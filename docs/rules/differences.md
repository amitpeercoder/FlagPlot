# Where the records and the code differ

Every place the rulebook's authors and editor found where a decision record's text and the code differ, or where the code does something odd that nobody decided. The rulebook states what the code does. The last column is the architect's ruling of Nov 12, 2026: the code stands, the code is to be fixed, or the record is to be changed. No ruling is carried out on this page; each names where it is done.

Each row was checked against the code when the page was written. Locations are files and functions in `crates/sim-core/src/`.
